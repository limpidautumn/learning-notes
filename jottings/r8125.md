# 随记：Debian Linux 下 RTL8125 2.5GbE 有线网卡驱动的离线安装流程

## 问题

在尝试对搭载 [RTL8125 2.5GbE 有线网卡](https://www.realtek.com/Product/Index?id=3962) 的计算机安装 [Debian 13.7](https://www.debian.org/News/2026/20260912) 时，无法访问 DHCP 服务器。进入日志

## 现状

**安装系统**

先使用 iso-dvd 进行离线安装；安装结束后进入系统。

**目标机器状态**

```text
camellia@Camellia:~$ . /etc/os-release && echo "$VERSION_CODENAME $DEBIAN_VERSION_FULL"
trixie 13.7
camellia@Camellia:~$ uname -r
6.12.107+deb13-amd64
```

amd64 架构，内核版本 6.12.107。

```text
camellia@Camellia:~$ lspci -nnk -d 10ec:8125
0B:00.0 Ethernet controller [0200]: Realtek Semiconductor Co., Ltd. RTL8125 2.5GbE Controller [10ec:8125] (rev 0c)
        Device Name: Realtek RTL8125D LAN
        Subsystem: ASUSTek Computer Inc. Device [1043:88e1]
        Kernel modules: r8169
camellia@Camellia:~$ sudo dmesg | grep r8169
[    0.865615] r8169 0000:0B:00.0: error -ENODEV: unknown chip XID 689, contact r8169 maintainers (see MAINTAINERS file)
```

驱动版本过旧，不支持新硬件。

针对 RTL8125D Rev B (XID 689) 的官方支持是在 Linux 6.14 内核版本中才被正式合并到主线 r8169 驱动里的。见 [Commit `b3593df`](https://github.com/torvalds/linux/commit/b3593df26ab19f114d613693fa8a92ab202803d0)

## 解决思路

使用 backport 升级内核较复杂，还可能导致后续 ABI 兼容问题。

这里使用厂商 r8125 DKMS (它是什么，参考 [DKMS](../notes/linux/dkms.md))。

## 修复过程

我手头上恰好有同为 amd64 架构的，装有 Debian Trixie 的联网计算机，下称“联网机”。也有 Windows 解决办法：原理相同，稍复杂些。

### 一、目标机抓取 dpkg-status

找一块移动存储介质，将其格式化为 ext4，挂载至目标机 `/mnt/udisk`。

```text
camellia@Camellia:~$ sudo cp /var/lib/dpkg/status /mnt/udisk/target-dpkg-status
```

解除挂载，然后拔出介质。

### 二、联网机下载依赖

将移动存储介质插入联网机，挂载至 `/mnt/udisk`。

**1. 下载 DKMS deb 包**

`6.12.107+deb13-amd64` 需替换为目标机内核发行版本号。

```text
avena@Avena:~$ USB=/mnt/udisk
avena@Avena:~$ ST="$USB/target-dpkg-status"
avena@Avena:~$ OUT="$USB/debs"
avena@Avena:~$ sudo mkdir -p "$OUT/partial"
avena@Avena:~$ sudo apt-get \
  -o Dir::State::status="$ST" \
  -o Dir::Cache::archives="$OUT/" \
  -o Debug::NoLocking=true \
  install --download-only --no-install-recommends \
    dkms linux-headers-6.12.107+deb13 linux-headers-amd64
```

忽略 sandbox 警告即可。

**2. 下载厂商 DKMS 驱动**

2.5G Ethernet LINUX driver r8125 for kernel up to 7.1, version 9.018.00, [列表](https://www.realtek.com/Download/List?cate_id=584) | [下载链接](https://www.realtek.com/Download/ToDownload?mode=first&type=direct&downloadid=3763). 将其拷贝至 `$USB/driver/r8125-9.018.00.tar.bz2`.

解除挂载，然后拔出介质。

### 三、目标机离线安装

将移动存储介质插入目标机，以只读形式挂载至 `/mnt/udisk`。

**1. 安装 deb**

```text
camellia@Camellia:~$ sudo apt install --no-download --no-install-recommends /mnt/udisk/debs/*.deb
camellia@Camellia:~$ sudo dkms --version
dkms-3.2.2
```

**2. 安装驱动**

```text
camellia@Camellia:~$ sudo tar -xjf /mnt/udisk/driver/r8125-9.018.00.tar.bz2 -C /usr/src
camellia@Camellia:~$ cd /usr/src/r8125-9.018.00
```

`autorun.sh` 写得非常烂，在现代发行版上不可用。顶层 `Makefile` 是给 `autorun.sh` 用的，需要绕过。

写一份 `dkms.conf`，位置 `/usr/src/r8125-9.018.00/dkms.conf`：

```conf
PACKAGE_NAME="r8125"
PACKAGE_VERSION="9.018.00"
BUILT_MODULE_NAME[0]="r8125"
BUILT_MODULE_LOCATION[0]="src"
DEST_MODULE_LOCATION[0]="/updates/dkms"
MAKE[0]="make -C /lib/modules/${kernelver}/build M=${dkms_tree}/${PACKAGE_NAME}/${PACKAGE_VERSION}/build/src modules"
CLEAN="make -C /lib/modules/${kernelver}/build M=${dkms_tree}/${PACKAGE_NAME}/${PACKAGE_VERSION}/build/src clean"
AUTOINSTALL="yes"
```

构建并安装：

```text
camellia@Camellia:~$ sudo dkms add     -m r8125 -v 9.018.00
camellia@Camellia:~$ sudo dkms build   -m r8125 -v 9.018.00
camellia@Camellia:~$ sudo dkms install -m r8125 -v 9.018.00
camellia@Camellia:~$ sudo dkms status
```

如果没有报错，进入下一步。

**3. Secure Boot, MOK 签名**

检查本机是否开启了 Secure Boot：

```text
camellia@Camellia:~$ mokutil --sb-state
```

若为 enabled，则需要签 MOK。

dkms 3.2.2 在第一次构建模块时，会在本机生成一套自签名的 MOK 密钥，并用它给编译出的 `.ko` 签名。

```text
camellia@Camellia:~$ sudo mokutil --import /var/lib/dkms/mok.pub  # 设置一次性密码
camellia@Camellia:~$ sudo mokutil --list-new  # 确认待 enroll
camellia@Camellia:~$ sudo reboot
```

重启时会出现蓝色 MokManager 界面，按 Enter 和上下键导航：

```text
Enroll MOK > View key > Continue > Yes > Password > Reboot
```

检查签名：

```text
camellia@Camellia:~$ sudo mokutil --test-key /var/lib/dkms/mok.pub
/var/lib/dkms/mok.pub is already enrolled
```

**4. 测试, 验证**

检查 DKMS 状态。

```text
camellia@Camellia:~$ sudo dkms status
r8125/9.018.00, 6.12.107+deb13-amd64, x86_64: installed
```

加载模块，测试。

```text
camellia@Camellia:~$ sudo modprobe -r r8169
camellia@Camellia:~$ sudo modprobe r8125
```

```
camellia@Camellia:~$ lspci -nnk -d 10ec:8125
08:00.0 Ethernet controller [0200]: Realtek Semiconductor Co., Ltd. RTL8125 2.5GbE Controller [10ec:8125]
        DeviceName: Realtek RTL8125D LAN
        Subsystem: ASUSTeK Computer Inc. Device [1043:88e1]
        Kernel driver in use: r8125
        Kernel modules: r8169, r8125
camellia@Camellia:~$ ip -br link
eno1 UP
```

如果没有问题，下一步。

**5. 固化**

黑名单 + 开机加载 + initramfs。

```text
camellia@Camellia:~$ printf 'blacklist r8169\n' | sudo tee /etc/modprobe.d/blacklist-r8169.conf
camellia@Camellia:~$ printf 'r8125\n' | sudo tee /etc/modules-load.d/r8125.conf
camellia@Camellia:~$ sudo update-initramfs -u -k all
```

重启验证。

```text
camellia@Camellia:~$ sudo reboot
```
