# u8g2 图形库
一个用于嵌入式设备的单色图形库。

## 使用方法
### CMake 项目
```cmake
# Link the u8g2 library.
FetchContent_Declare(u8g2
  GIT_REPOSITORY https://github.com/olikraus/u8g2.git
  GIT_TAG main
)
FetchContent_MakeAvailable(u8g2)
target_compile_definitions(u8g2 PUBLIC U8X8_WITH_USER_PTR) # enable u8x8->user_ptr for OOP in C++.
target_link_libraries(${CMAKE_PROJECT_NAME} u8g2)
```

## bdfconv
用于将 BDF 点阵字体转换为 u8g2 库可用的 C 数组字体。

### 工具下载
[bdf 字体文件](https://github.com/olikraus/u8g2/tree/master/tools/font/bdf) | [bdfconv 工具](https://github.com/olikraus/u8g2/tree/master/tools/font/bdfconv)

下载 `bdfconv.exe`，及需要转换的字体文件。

### 使用方法
```powershell
./bdfconv.exe -h
```
