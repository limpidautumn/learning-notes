# 外部中断
External Interrupt

[视频教程](https://www.bilibili.com/video/BV1M24y1473t) | [跳转到总结部分](https://www.bilibili.com/video/BV1M24y1473t?t=677)

## 信号路径

I/O 引脚 -> 施密特触发器 -> 复用功能输入 -> 边沿检测电路 -> 请求挂起寄存器 -> 嵌套向量中断控制器(NVIC) -> 中断处理函数

## 优先级
抢占优先级 / 响应优先级

1. **中断几乎同时到达**：先检查抢占优先级，再检查响应优先级，最后是中断向量表的顺序。

2. **某中断正在执行中，另一中断突然到达**：检查抢占优先级。

抢占优先级 / 响应优先级 总共4位，可以在 STM32CubeMX 中分配各自位数。
